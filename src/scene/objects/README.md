# Объекты сцены

Всё, что живёт на поверхности, описывается одинаково. `core/` задаёт контракт,
папка объекта его выполняет. Никакой другой слой не знает, что такое огонь.

```
objects/
  core/                    контракт и общие правила
    SurfaceObjectDefinition.ts  что обязан предоставить объект
    objectRegistry.ts           реестр: регистрация при импорте модуля
    settingsSchema.ts           декларативные параметры + чтение/запись по пути
    fogVisibility.ts            глубина по камере и растворение в тумане
    objectFocus.ts              когда анимировать и какую прозрачность держать
    objectYaw.ts / objectFacing.ts   детерминированный разворот и кадрирование
    selectVisibleObjects.ts     что рисуем в этом кадре (ближние, с учётом лимита)
    pickObjectAtScreen.ts       попадание пальцем по поверхности
  fire/                    воксельный огонь
  index.ts                 импорт модулей = регистрация объектов
```

## Добавить новый объект

1. Создать `objects/<kind>/`.
2. Настройки: тип + дефолты (`<kind>Settings.ts`), zustand-стор, схема из
   `numberField` / `colorField` / `switchField`.
3. Симуляция — чистые числа, без three. Так она покрывается `*.spec.ts`
   и гоняется в vitest без нативного рантайма.
4. Рендер: `Field` (все объекты этого вида на поверхности) и `Preview`
   (один объект отдельно). Инстансинг обязателен — один draw call на слой.
5. `<kind>Definition.ts`: собрать всё в `SurfaceObjectDefinition` и вызвать
   `registerSurfaceObject`.
6. Добавить строку импорта в `objects/index.ts`.

Больше ничего. Сцена подхватит `Field`, экран настроек сам нарисует все
параметры со слайдерами и живым превью сверху.

## Правила, которые нельзя нарушать

- **Один draw call на слой.** Никаких мешей на объект.
- **Симуляция отдельно от рендера.** Классы симуляции не импортируют three.
- **Туман — это выключатель.** Объект за дальней границей тумана не
  симулируется и не занимает инстансы: его всё равно не видно.
- **Настройки — данные.** UI строится по схеме, а не пишется руками под каждый
  объект.
