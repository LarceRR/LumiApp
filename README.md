# Lumi

Приложение о том, чтобы замечать хорошее рядом. У пары есть общее пространство с
трёхмерной поверхностью: приятный момент ставится как огонёк, сложный — как
облако. Объекты живут, тускнеют и остаются в истории.

Репозиторий состоит из двух частей:

- корень — мобильное приложение (React Native + Expo, iOS и Android);
- [`backend/`](backend/README.md) — API (NestJS + Fastify + PostgreSQL).

## Запуск приложения

```bash
npm ci
npm start          # затем i — iOS, a — Android
```

Без настроенного API приложение работает целиком локально: репозитории
подставляются из `src/infrastructure/local`, данные лежат в AsyncStorage, а
доменные правила соблюдаются те же, что на сервере. Это нужно, чтобы UI и сцену
можно было разрабатывать без запущенного бэкенда.

Чтобы подключиться к API, добавьте адреса в `app.json` → `extra`:

```json
{
  "extra": {
    "apiBaseUrl": "http://192.168.0.10:3000/v1",
    "websocketUrl": "ws://192.168.0.10:3000/realtime"
  }
}
```

## Команды

| Команда            | Назначение                              |
| ------------------ | --------------------------------------- |
| `npm start`        | Metro и Expo Dev Client                 |
| `npm run android`  | запуск на Android                       |
| `npm run ios`      | запуск на iOS                           |
| `npm run verify`   | типы + линтер + тесты (то же, что в CI) |
| `npm run lint:fix` | автоисправление линтера и формата       |

Git-хуки включаются автоматически при `npm ci` (`core.hooksPath` → `.githooks`):
перед коммитом проверяется формат изменённых файлов, перед пушем — весь `verify`.

## Структура

```
src/
  app/            конфигурация, DI-контейнер, провайдеры, маршруты Expo Router
  design-system/  токены (цвет, отступы, типографика, motion) и компоненты
  domains/        <контекст>/{domain,application,infrastructure,presentation}
  scene/          трёхмерная сцена: камера, свет, материалы, поверхность, объекты
  infrastructure/ http, storage, realtime, офлайн-очередь, кэш запросов
  shared/         ошибки, логгер, контракты API, утилиты
  assets/         модели и шрифты
```

Маршруты Expo Router лежат в `src/app/routes` (см. `extra.router.root` в
`app.json`), поэтому слой `app` остаётся обычным слоем архитектуры, а не папкой
навигации.

Домены не знают друг о друге и не знают про UI. Внутри домена:

- `domain` — сущности, value objects, правила и порты репозиториев;
- `application` — сценарии, собранные из портов;
- `infrastructure` — адаптеры: HTTP-репозиторий и локальный репозиторий;
- `presentation` — экраны, компоненты и хуки.

Зависимости собираются один раз в `src/app/container` и раздаются через контекст,
так что экран получает сценарий, а не знание о том, откуда приходят данные.

## Сцена

Сцена — отдельный слой, а не часть экрана. Что важно в ней:

- **Один draw call на тип объекта.** Огоньки рисуются `InstancedMesh`, контактные
  тени — тоже инстансами.
- **Качество подстраивается под устройство.** `PerformanceMonitor` следит за
  частотой кадров и меняет уровень качества, `PixelRatioController` — разрешение
  буфера. Сглаживание выставляется один раз при создании контекста.
- **Жесты живут на UI-потоке.** Собственный `CameraController` и
  `react-native-gesture-handler` вместо OrbitControls: камера не спорит с
  касаниями по интерфейсу.
- **Подписи проецируются, а не рендерятся в 3D.** `LabelProjector` считает
  экранные координаты внутри канваса и передаёт их в `SharedValue`, надпись
  «Облако» рисуется обычным текстом поверх сцены.

## Тесты

```bash
npm test
```

Юнит-тесты лежат рядом с кодом (`*.spec.ts`) и покрывают чистую логику: доменные
правила, офлайн-очередь, преобразование координат сетки. Компонентные тесты
используют React Native Testing Library, сквозные — Detox.
